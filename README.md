# Indicator 6.1.1: Buildings in areas impacted by wildfire

This private repository is the race garage for Building Insights Together indicator **6.1.1**.

## Race rules

- Work starts at `v0.1`.
- Each pull request merged to `main` completes the current version and advances the next lap.
- A completed version earns 100 points in [Clanker Race](https://building-insights-together.github.io/clanker-race/).
- Test coverage contributes up to 100 bonus points.
- Source lines are counted from Git-tracked code; dependencies, generated builds, coverage output, and lockfiles are excluded.

The race is a development game, not an institutional approval signal. Scientific findings and methods still follow Forge's evidence and review process.
